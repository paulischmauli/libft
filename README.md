# Libft

## Description

Libft is a own C library, built as part of the 42 curriculum. Goal is to reimplement a set of standard libc functions and other utilities learn how low-level stuff works and to use them in later projects.

The library is compiled into a static archive, `libft.a`, written in C according to the 42 Norm.

### Contents

**Part 1: libc functions**

| Category | Functions |
|---|---|
| Character checks | `ft_isalpha`, `ft_isdigit`, `ft_isalnum`, `ft_isascii`, `ft_isprint` |
| Character conversion | `ft_toupper`, `ft_tolower` |
| Strings | `ft_strlen`, `ft_strlcpy`, `ft_strlcat`, `ft_strchr`, `ft_strrchr`, `ft_strncmp`, `ft_strnstr`, `ft_strdup` |
| Memory | `ft_memset`, `ft_bzero`, `ft_memcpy`, `ft_memmove`, `ft_memchr`, `ft_memcmp`, `ft_calloc` |
| Conversion | `ft_atoi` |

**Part 2: additional functions**

`ft_substr`, `ft_strjoin`, `ft_strtrim`, `ft_split`, `ft_itoa`, `ft_strmapi`, `ft_striteri`, `ft_putchar_fd`, `ft_putstr_fd`, `ft_putendl_fd`, `ft_putnbr_fd`

**Part 3: linked lists**

The library uses this node type:

```c
typedef struct s_list
{
	void			*content;
	struct s_list	*next;
}	t_list;
```

Functions: `ft_lstnew`, `ft_lstadd_front`, `ft_lstsize`, `ft_lstlast`, `ft_lstadd_back`, `ft_lstdelone`, `ft_lstclear`, `ft_lstiter`, `ft_lstmap`

### Technical choices

- The `is*` functions return exactly 1 on a match and 0 otherwise, as the subject requires.
- Functions that allocate memory return `NULL` on failure and free any partial work. `ft_split` and `ft_lstmap` clean up everything they allocated before returning `NULL`.
- Helper functions are `static`, so their scope stays limited to their own file.

## Instructions

### Requirements

- `cc` (or any C compiler)
- `make`
- `ar`

### Build

```bash
make          # builds libft.a
make clean    # removes object files
make fclean   # removes object files and libft.a
make re       # fclean, then all
```

The Makefile compiles with `-Wall -Wextra -Werror` and does not relink if nothing changed.

### Usage

Include header in your code and link against the library:

```c
#include "libft.h"
```

```bash
cc -Wall -Wextra -Werror main.c -L. -lft -o program
```

### Example

```c
#include "libft.h"

int	main(void)
{
	char	**words;

	words = ft_split("hello 42 vienna", ' ');
	/* words: "hello", "42", "vienna", NULL */
	/* free each string, then the array */
	return (0);
}
```
